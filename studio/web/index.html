🤖 Let an AI coding agent do the recovery

The studio writes AGENT_TASK.md into your workspace and opens the agent you pick in its own console window, in that folder. You answer its permission prompts there; the studio never turns on auto-approve. The package and tool output are untrusted, and what the agent reads goes to its provider. The package and workspace come from the Recovery tab (Windows build folders work here).
