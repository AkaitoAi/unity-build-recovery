# Third-party tools

The studio does not ship these tools. It downloads or uses them from your tool folder, and each keeps its own licence. Check each project's page before redistributing anything it produces.

| Tool | Used for | Source |
|---|---|---|
| 7-Zip | Unpacking APK, XAPK, ZIP | https://www.7-zip.org/ |
| AssetRipper | Ripping Unity assets | https://github.com/AssetRipper/AssetRipper |
| Il2CppDumper | IL2CPP type information | https://github.com/Perfare/Il2CppDumper |
| Cpp2IL | IL2CPP recovery | https://github.com/SamboyCoding/Cpp2IL |
| JADX | Java decompilation | https://github.com/skylot/jadx |
| GDRE Tools | Godot project recovery | https://github.com/GDRETools/gdsdecomp |
| REA (optional) | Static reverse engineering for agents | https://github.com/morluto/rea |
| Craft Anything (optional) | Gameplay reconstruction | https://github.com/storytold/craft-anything |
| Ghidra, ILSpy (optional) | Native and .NET decompilation | NSA Ghidra, icsharpcode/ILSpy |

Use this tool only on builds you own or are allowed to recover.
